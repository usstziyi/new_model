# 10 个分类类别的来源（论文素材）

> 用途：撰写完整论文 Methods 时直接参考。对应实现见
> `scripts/make_text_csv.py` 与 `plan_baseline_lda/dataset.py`。

## 一句话概括

对每个被试、每个任务，先按句子去重，再统计句子的语义类别 `type_number` 频次，取频次最高的 10 类作为分类目标。

## 中文 Methods 段落草稿

原始数据为 ds005170 中文句子 EEG 数据集，每句标注一个语义类别（共 39 类，编号 0–38）。由于同一句子会在多个 run 中重复呈现，我们以"被试 × 任务"为单位按句子文本去重，同一句仅保留首次出现（最早 run、run 内最小位置）。随后在去重后的句表上统计各类别的句子数，取频次最高的 10 类作为本研究的分类目标，并按类别编号升序重映射为 0–9。EEG 数据依据句表中记录的 `(run, pos)` 回溯原始 run 文件逐试次提取，取 122 个 EEG 通道，不做降采样。阅读与想象两个任务分别独立选类与建模。

## 必须写清的四个点

1. **去重口径**：先按句子去重再统计，因此"10 类"是按**唯一句子数**排序，不是按试次数。
2. **选类范围**：逐被试、逐任务独立选类。实测 5 名被试 × 2 个任务共 10 张表中，9 类完全相同，仅第 10 类在"产品和质量保证"（32）与"设备故障和环境问题"（30）之间变化，属频次边界抖动；论文中需说明"独立选类"这一口径。
3. **标签来源**：类别来自数据集自带的 `type_number` 语义标注，非人工重标。
4. **EEG 与句表的对应**：试次表仅存 `(run, pos)` 索引，信号始终从原始 pkl 提取，避免二次存储。

## 处理流程摘要

1. 解析 pkl 文件名，按被试收集，组内按 run 数值升序排列。
2. 逐 run 逐试次记录：全局序号、天数、run、run 内位置、句子、非标点字符数、类别 id 与名称。
3. 以"被试 × 任务"的整张表为单位按句子去重，保留首次出现并重排序号。
4. 统计类别频次，取前 10 类，按类别 id 升序映射为 0–9。
5. 按 `(run, pos)` 回到原始 pkl 取 EEG，拼成 `(N, 122, T)`。
