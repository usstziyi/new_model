图 S4  三种协议的逐折准确率分布

图注：每个空心点为一次留出（一折）的测试准确率，箱体为中位数与四分位距，须为 1.5 倍四分位距范围，须端以外的点按原值显示。参考 5 折为 5 名被试的同 run 随机划分（共 25 折）；留一 run 为每名被试各 44~45 折（共 224 折）；留一采集日为每名被试 5 折（共 25 折）。三组均值分别为 0.224、0.114 和 0.096，点线为 10% 机会水平。留一 run 的折间分布跨越机会水平（0.000~0.356），说明该协议下单个 run 的成绩取决于"该 run 是否恰好可迁移"，不存在稳定的类别信息；留一采集日的 25 折全部落在 0.050~0.130，其中 15 折低于 0.10。
