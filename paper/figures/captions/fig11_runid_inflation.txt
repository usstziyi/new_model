图 11  随机划分虚高与 run 指纹可解码性的关系

图注：5 名被试、10 类句类，机会水平 10%。(a) 每个模型的随机划分虚高（同 run 随机 5 折准确率 − LORO 准确率）：柱高为 5 名被试均值，误差棒为被试间标准差，空心圆为单个被试。线性基线为 10.5 ± 1.1 个百分点，EEGNet 为 4.2 ± 0.7，频域 CNN 为 4.3 ± 1.3。(b) 横轴为 run 身份可解码性（以 run 为标签的随机 5 折交叉验证准确率，45 类，sub-05 为 44 类；机会水平 2.2%），纵轴为超出 chance 的优势；实心点为随机 5 折（cv5），空心点为 LORO，每个点是一个「被试 × 模型」，共 15 个实心点。线性基线的 run 身份准确率为 98.5%，EEGNet 为 83.5%，频域 CNN 为 89.8%；三种模型 LORO 超出 chance 的优势均集中在 1.6~2.2 个百分点，且不随 run 指纹强弱变化。实心点的线性拟合 r = 0.51（n = 15，p = 0.051），提示指纹越强、随机划分虚高越大的趋势，但样本量不足以支持强推断，仅作为机制解释的辅助证据。
