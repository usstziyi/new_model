图 12  深度基线与线性基线的逐 run 配对比较（留一 run）

图注：5 名被试共 224 个留出 run（每名被试 44~45 个），每个点为一个 run；横轴为线性基线（log 频带功率 + 收缩 LDA）的留一准确率，纵轴为深度模型的留一准确率，虚线为 y = x，点线为机会水平 10%。(a) EEGNet：均值由 11.4% 变为 11.9%，Pearson r = 0.31（p = 2×10⁻⁶），平均差 +0.45 个百分点，Wilcoxon 符号秩 p = 0.80，97 个 run 变好、101 个变差。(b) 频域 CNN：均值由 11.4% 变为 11.5%，r = 0.40（p = 3×10⁻¹⁰），平均差 +0.02 个百分点，p = 0.99，100 个 run 变好、101 个变差。两个模型的正相关说明逐 run 的难易结构在时域与频域表示之间具有可迁移性；但均值差与符号检验表明，在严格留一协议下两种深度模型与线性基线没有可分辨的优劣。
