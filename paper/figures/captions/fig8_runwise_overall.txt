图 8  run-wise 归一化在三种评估协议下的句类准确率

图注：5 名被试、10 类句类，机会水平为 10%（点线）。柱高为 5 名被试的平均值，误差棒为被试间标准差。(a) 同 run 随机 5 折、(b) 留一 run（LORO）、(c) 留一采集日（LODO）；每个面板依次为无归一化（灰）、归纳式 z-score（蓝）、归纳式仅中心化（蓝＋斜线）、直推式 z-score（橙）、直推式仅中心化（橙＋斜线）。归一化在每名被试内、按 run 独立估计均值与标准差：z-score 同时减均值并除标准差，仅中心化只减均值。归纳式的统计量只来自训练试次，直推式使用该 run 的全部试次（含测试试次）。无归一化时三协议的准确率分别为 22.4%、11.9% 和 9.5%；随机划分下归一化后降至 11.8% 和 9.5%（归纳/直推 z-score），相对机会水平的优势分别损失 85% 和 104%（后者已低于机会水平）；留一 run 下反而降至 9.6% 和 9.4%，留一采集日下为 8.9% 和 9.1%，均未超过机会水平。仅中心化与 z-score 的差异不超过 0.4 个百分点，说明 run 指纹主要存在于加性均值偏移中，额外除以 run 内标准差没有带来收益。随机 5 折取逐折准确率均值，两种留一协议取池化准确率；所有条件使用相同的特征（逐通道 log 频带功率）与分类器（收缩 LDA）。
