图 9  run-wise 归一化的损失集中在原本准确率较高的 run

图注：数据为 5 名被试共 224 个 run（每名被试 44~45 个），句类数为 10 类，机会水平为 10%。(a) 横轴为无归一化时该 run 的留一准确率，纵轴为归一化后准确率的变化（归一化后 − 无归一化）；空心圆为归纳式 z-score 的单个 run，黑实线为线性回归拟合，虚线为零，点线为机会水平。任一 run 只要位于虚线下方即表示归一化使其变差。回归斜率为 −0.69，与零线的交点在原准确率 8.9% 处，即原本低于该水平的 run 略有回升、高于该水平的 run 随原准确率上升而加速下降；Pearson r = −0.71（归纳式）与 −0.77（直推式）。(b) 按无归一化准确率五分位（Q1 最低、Q5 最高）分组的平均变化，蓝色（灰度版浅灰）为归纳式、橙色（灰度版深灰）为直推式，共 5 组、每组 44~46 个 run。五组平均变化依次为 +3.8、+0.8、−1.9、−2.1 和 −9.4 个百分点（归纳式），直推式对应 +4.0、+0.8、−1.3、−3.3 和 −10.9 个百分点；总体平均变化为 −1.8 和 −2.1 个百分点。Q1 的平均原准确率仅 3.1%（低于机会水平），归一化后回升至 6.9%；Q5 的平均原准确率达 21.8%，归一化后回落至 12.4%。需要注意，(a) 中纵轴的差值本身包含 −横轴，即使归一化后的成绩与 run 无关，两者也会呈负相关；更稳健的证据是原准确率与归一化后准确率的关系，其 Pearson r 分别为 +0.41（归纳）和 +0.26（直推）、回归斜率 +0.31 和 +0.18，即 run 间原有的准确率差异只剩约三成被保留。126 个原本不低于 10% 的 run 中，有 53 个在归一化后跌破机会水平、13 个跌破 5%。这说明随机划分下的高准确率并非来自跨 run 稳定的句义信息，而是来自与 run 身份共线的成分，去除 run 均值时这部分信息被一并删除。
