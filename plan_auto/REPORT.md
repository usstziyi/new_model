# Chisco EEG 语义解码实验报告（`plan_auto`）

日期：2026-11-15　｜　数据：`datasets/top10_imagine`、`datasets/top10_reading`、`datasets/preprocessed`

***

## 摘要

夜里跑完了 10 组实验、5 名被试 × 2 个任务 × 10 个语义类别。结论比预想的更值得写下来：

- 在**常规的“按 run 分组交叉验证”**下，最好的模型（通道组集成 / ShallowFBCSP / 跨任务迁移）能到 **12%–13%**，看似显著高于 10% 的机会水平；
- 但审计发现数据集存在一个**强混杂**：同一 run 内，10 个语义类别是按时间块顺序呈现的，**只用“试次在 run 内的归一化位置”分类，准确率就有 35.4%**（run 内类别平衡召回 39.5%）；
- 一旦用 **1.5 Hz 高通 + 按位置多项式去趋势**把这一成分剔除，所有模型的 10 类准确率回落到 **9.6%–9.8%**，run 内类别平衡召回 **8.5%–9.5%**，即**机会水平甚至略低**；
- 为排除“线性特征漏掉非线性结构”，又用 **ShallowFBCSP 直接在位置去趋势后的时域波形上训练**：run 内类别平衡召回 **10.39%**（95% CI \[9.62, 11.20]，run 内置换 p = 0.39），仍与机会不可区分；
- **训练级置换**（run 内打乱标签后重训 300 次）给出决定性证据：打乱标签后同一流程仍得到 **11.8%**，高于真实标签的 11.3%（p = 0.90）；位置去趋势后 p = 0.91 / 0.99；
- **半合成注入**校准了流程灵敏度：频带功率模型在注入 SNR≈0.5 时可稳定检出，而真实数据在校正后对应 SNR≈0，说明真实语义效应低于该检测阈（若存在）。

**因此，在这批数据上，我无法诚实地声称“训练出了能显著解析语义的模型”。** 之前随机试次划分得到的 19% 主要是同一 run 内试次泄漏 + 呈现顺序混杂。这个结论本身是这晚最有价值的产出：它解释了为什么此前的自研模型时好时坏，也给出了下一步真正能验证语义解码的实验设计。

不过，所有代码、缓存、模型权重、预测概率与日志都已保存，流程图、混淆矩阵、混杂对照图也生成了，明天可以直接接着改设计继续跑。

## 1. 数据与评估协议

| 项目  | 设置                                                                                           |
| --- | -------------------------------------------------------------------------------------------- |
| 被试  | sub-01 … sub-05                                                                              |
| 类别  | 全局 top10：2,10,13,14,19,21,24,26,31,32（sub-05 的 14 原本缺失，已从原始 pkl 现场抽取补齐）                      |
| 试次数 | 想象 2076–2524 / 人；阅读 2042–2515 / 人                                                            |
| 信号  | 122 导 EEG，想象段 3.3 s、阅读段 5 s；500 Hz → 250 Hz                                                  |
| 滤波  | 0.5–45 Hz 零相位带通（另做 1.5–45 Hz 版本用于混杂控制）                                                       |
| 划分  | **按 run 分组 5 折**：同一 run 的试次只会出现在训练或测试一侧                                                      |
| 选型  | 每折再从训练 run 留 25% 作验证集，验证集选配置，测试折不参与选型（exp01/03）                                              |
| 指标  | accuracy、macro-F1、**句长配平子集准确率**、**run 内类别平衡召回**、按 run 的 cluster bootstrap 95% CI、run 内标签置换 p |

句长配平：对每个句长值，取 10 个类别中该长度样本的最小数量做等量抽样，使各类 `n_chars` 分布完全一致，从而排除“类别 ↔ 句长”这条捷径（仅用句长的分组 CV 基线本身就有 **12.2%–15.0%**）。

## 2. 关键发现：类别 = 时间块

每个 run 内，同一类别的试次集中在一段连续时间；类别平均位置从 run 开头到结尾单调上升（sub-01 各类平均位置 0.04 → 0.96，类别与位置的 Spearman ρ = 0.91）。

- 仅用 4 阶多项式位置特征（不含任何 EEG）做 10 类分类：**accuracy 35.4%**，run-balanced recall **39.5%**。
- 阅读任务同样：位置基线 **34%–38%**。

这意味着任何随 run 缓慢变化的分量（电极漂移、阻抗、疲劳、低频功率、肌电基线）都能伪装成语义信息。按 run 分组只能挡住“同一 run 内的试次泄漏”，**挡不住“run 内位置 ↔ 类别”的对应关系**。

### 3.2 深度模型（exp02）

- **ShallowFBCSP**：125 Hz、逐试次 z-score、平移/缩放/噪声/通道丢弃/时间遮挡增强、5 折分组 CV、按验证集选 top-3 epoch 快照集成、5 个平移 TTA。
- 合并 OOF：accuracy **0.1281**（95% CI [0.1161, 0.1406]），句长配平 **0.1214**；但 run 内类别平衡召回只有 **0.101**。
- EEGNet 在相同设置下未收敛（验证集长期停在 10–11%，早停后测试 8–10%），已停止；诊断脚本 `exp02_deep/diagnose.py` 证明它在 300 条小样本上可以过拟合（训练 acc 74%），问题在数据信噪比与强增强，而不是代码错误。
- 结论：深度模型复现了特征模型的“12–13%”，没有突破。

### 3.4 阅读 ↔ 想象 跨任务迁移（exp08）

同一句子的阅读段和想象段来自同一试次，配对评估会共享慢漂移。两种评估对比：

| 评估方式                | 平均 accuracy（5 被试） |
| ------------------- | ----------------- |
| 配对（阅读→想象）           | 0.184 ± 0.024     |
| 配对（想象→阅读）           | 0.199 ± 0.017     |
| **按 run 分离（阅读→想象）** | **0.119 ± 0.008** |
| **按 run 分离（想象→阅读）** | **0.121 ± 0.009** |
| 任务内分组 CV（想象 / 阅读）   | 0.120 / 0.119     |

配对评估的 18–20% 是典型的**配对泄漏**：同一试次的阅读段和想象段共享电极漂移、被试状态与时间位置。按 run 分离后回落到 12%，与任务内一致——说明 12% 里也没有多少可迁移的语义，更多是共同的位置/漂移成分。

### 3.5 决定性实验：位置去趋势（exp09）

对 1.5 Hz 高通缓存重新提特征，再做两种处理：

1. `raw`：直接分组 CV；
2. `posdetrend`：对每个 run、每个特征维度，用三次多项式拟合“特征 \~ run 内归一化位置”，减掉拟合值，只保留同位置附近的差异。

| 设置                       | accuracy | **run-balanced recall** | 句长配平 acc |
| ------------------------ | -------- | ----------------------- | -------- |
| 仅位置（无 EEG）               | 0.354    | **0.395**               | 0.357    |
| raw + 频带集成               | 0.121    | **0.096**               | 0.115    |
| raw + 全频带 LDA            | 0.113    | **0.097**               | 0.109    |
| raw + Hjorth             | 0.116    | **0.095**               | 0.113    |
| raw + ERP                | 0.097    | **0.094**               | 0.091    |
| **posdetrend + 频带集成**    | 0.097    | **0.085**               | 0.091    |
| **posdetrend + 全频带 LDA** | 0.097    | **0.089**               | 0.094    |
| **posdetrend + Hjorth**  | 0.097    | **0.091**               | 0.096    |
| **posdetrend + ERP**     | 0.098    | **0.095**               | 0.088    |

去趋势后所有配置都在机会线附近或以下。`position_only` 仍高达 0.395，说明去趋势确实拆掉了位置成分，而 EEG 里没有剩下一致的语义结构。

### 3.6 深度模型 + 位置去趋势（exp10）

把上面的“位置去趋势”从特征层搬到**时域波形**：1.5 Hz 高通后，对每个 run、每个
通道，用 5 阶多项式拟合“电压 \~ 归一化位置”，减去拟合值；再用 ShallowFBCSP
训练（同样的 5 折分组 CV、增强、TTA）。

| 被试     | accuracy | run-balanced recall | 句长配平 acc |
| ------ | -------- | ------------------- | -------- |
| sub-01 | 0.113    | 0.096               | 0.101    |
| sub-02 | 0.132    | 0.108               | 0.131    |
| sub-03 | 0.127    | 0.110               | 0.124    |
| sub-04 | 0.119    | 0.102               | 0.115    |
| sub-05 | 0.122    | 0.106               | 0.119    |

合并 run-balanced recall **0.1039**，按 run 的 cluster bootstrap 95% CI
**\[0.0962, 0.1120]**；run 内标签置换零分布均值 0.1028，**p = 0.386**。仍与
机会不可区分（准确率 11%–13% 仍主要来自残余的 run 内结构）。

### 3.8 半合成注入：流程能检出多大的语义效应（exp11）

向真实 EEG 注入类别特异的 alpha 爆发（每类 30 个通道、8–12 Hz、随机初相、
Hann 包络），幅度按 `SNR = 注入 RMS / 信号 RMS` 控制，再跑完全相同的按 run
分组 CV。这样可以把“未检出”解释为“真实效应低于检测阈”，而不是“流程无效”。

| 注入 SNR | bp raw | bp posdetrend | Hjorth raw | ERP raw |
|---|---|---|---|---|
| 0（真实数据） | 0.1131 | 0.0965 | 0.1155 | 0.0971 |
| 0.10 | 0.1127 | 0.0962 | 0.1161 | 0.0969 |
| 0.20 | 0.1161 | 0.0979 | 0.1162 | 0.0971 |
| 0.30 | 0.1278 | 0.1059 | 0.1172 | 0.0969 |
| 0.50 | 0.2237 | 0.1622 | 0.1222 | 0.0968 |
| 0.80 | 0.4533 | 0.2930 | 0.1580 | 0.0971 |

按“run-balanced recall 超过真实数据基线 + 2 sd”定义检测阈：**bp 为 SNR≈0.5，
Hjorth 为 0.8，ERP 对 alpha 注入不敏感（未检出）**。真实数据在校正后约 9.6%，
对应 SNR≈0；也就是说，若存在语义效应，其相对幅度低于约 0.3–0.5 的注入信号，
否则本流程应当能看见。

### 3.9 训练级置换检验（exp12）

之前的置换只打乱已训练模型的 OOF 预测；这里在**每个 run 内打乱标签后重新
训练** LDA（300 次/被试、5 折分组 CV），得到真正的训练级零分布。

| 特征 | 指标 | 观测均值 | 零分布均值 | p |
|---|---|---|---|---|
| raw bp | accuracy | 0.1131 | **0.1182** | 0.904 |
| raw bp | run-balanced recall | 0.0973 | 0.1028 | 0.937 |
| posdetrend bp | accuracy | 0.0965 | 0.1008 | 0.907 |
| posdetrend bp | run-balanced recall | 0.0889 | 0.0996 | 0.993 |

最关键的发现是：**把标签彻底打乱后，同一流程反而得到更高的 11.8%**，说明常规
分组 CV 下的 12%–13% 完全可以由 run 内类别构成与位置结构解释，不需要任何
语义信息。位置去趋势后，观测值甚至略低于零分布均值。

![置换零分布](figures/permutation_null.png)

## 4. 结论

1. **不能声称显著语义解码。** 所有“高于机会”的结果都能被以下三条解释：run 内类别顺序（最强，位置基线 35–40%）、类别的句长分布差异（12–15%）、配对试次共享漂移（跨任务 18–20%）。训练级置换进一步显示：打乱标签后同一流程仍有 11.8%（高于观测 11.3%，p=0.90）。
2. **按 run 分组的交叉验证还不够**：当刺激顺序固定时，必须同时控制 run 内位置（或改用随机化呈现）。run-balanced recall 与位置去趋势是两个实用工具，本仓库已实现；半合成注入给出该流程的检测阈约为 SNR 0.5（频带功率）。
3. **深度模型没有带来突破**：ShallowFBCSP 与线性特征模型在混杂控制前后表现一致；直接把 ShallowFBCSP 训练在位置去趋势后的时域波形上，run-balanced recall 10.39%（CI 含 10%，p=0.39）。在当前信噪比下，换更大模型不是关键。
4. **阅读任务并不比想象任务容易**：两者都是 12–13%，说明当前瓶颈不是任务类型，而是数据设计/单试次信噪比。

***

## 5. 如果继续做：优先级建议

1. **改评估，不改模型**：任何新结果先看 `position_only` 基线、`run_balanced_recall` 和 `posdetrend` 版本；只有三者都过线才值得继续。
2. **位置平衡采样**：在每个 run 内按位置分层、跨类别等量取样；若某位置只有单一类别，则该 run 对语义解码无贡献，应剔除。
3. **随机化/伪随机化呈现顺序**（下一轮采集），或使用数据集里顺序被打乱的 run 子集做训练/测试。
4. **重复呈现 + 试次平均**：同一句子重复 3–5 次，单试次解码改为小样本平均，能显著提升 SNR。
5. **跨被试 + 位置作为协变量**：混合效应模型或对抗去除位置，而不是简单分组 CV。
6. **时频/源空间**：语义若存在，更可能在刺激锁时的 theta/alpha 相位或源空间网络，而不是宽带功率；可尝试 CCA/时频相位特征。

## 7. 局限

- 仅 5 名被试、每类约 200 试次；单试次效应量小，统计功效有限，不能排除更弱（<1%）的真实语义效应。
- 位置去趋势假设“位置效应可由三次多项式描述”，可能过度或不足去除；但 `position_only` 在去趋势前后仍保持高可分性，说明主要成分被目标化处理。
- 阅读/想象段的切分来自数据集预处理，具体锁时未知；若存在未对齐的锁时成分，宽带功率特征可能错过。
- 本报告没有做源定位、相位耦合或跨被试表征相似性分析，这些仍可能揭示更细的语义结构。
