# 投稿配图规范（EEG 配对比较图）

本文件记录 `plan_loro_lodo` 系列配图的最终交付标准，供后续新增图形时直接套用。
所有参数均在 300–600 dpi 印刷尺寸下核对过，不是屏幕预览参数。

---

## 1. 适用范围

- LORO / LODO 与随机参考的逐 run、逐日配对比较
- 单被试（2 面板）与多被试（2×3 小倍数）两种版式
- 同一图形需同时提供**灰度版**与**彩色版**，编码逻辑一致

## 2. 目录与命名

```
outputs/figures/
├── gray/             正文灰度版（投稿默认）
├── colors/           正文彩色版（期刊支持彩图时使用）
├── supplementary/    补充材料（gray/、colors/，编号 S1、S2）
├── captions/         图注 txt（标题 + 图注）
└── standards/        本规范
```

命名规则：`fig{序号}_{内容}_{width}.{ext}`，图注文件同名（`.txt`）。补充材料使用 `figS{序号}_...`。

| 片段 | 取值 |
|---|---|
| 序号 | 按正文出现顺序 1~7；补充材料为 S1、S2 |
| 内容 | `protocol` / `run_fingerprint` / `band_sweep` / `channel_effect` / `permutation` / `loro_all` / `lodo_all` / `loro_s01` / `lodo_s01` |
| width | `170mm`（双栏）/ `80mm`（单栏，仅单被试 2 面板） |
| ext | `pdf` / `tif` |

示例：`fig1_protocol_170mm.pdf`、`figS1_loro_s01_80mm.tif`

图注文件：`fig{序号}_{内容}.txt`，如 `fig6_loro_all.txt`、`figS1_loro_s01.txt`。

## 3. 尺寸与分辨率

| 版式 | 画布 | 成品（紧裁后） | 用途 |
|---|---|---|---|
| 双栏单被试 | 170 × 72 mm | ≈168 × 71 mm | 2 面板横排 |
| 单栏单被试 | 80 × 112 mm | ≈79 × 110 mm | 2 面板竖排 |
| 双栏多被试 | 170 × 112 mm | ≈169 × 119–127 mm | 2×3 小倍数 |

- 线条图分辨率 **600 dpi**；TIFF 使用 **LZW 压缩**
- 同时输出 **PDF 矢量**（`pdf.fonttype = 42`，字体嵌入，文字可检索）
- 成品宽度必须 ≤ 版心；若目标期刊为 165/168 mm，按实际版心重出

## 4. 字体与字号

| 项目 | 设置 |
|---|---|
| 字体族 | `["Times New Roman", "SimSun"]`（**必须是列表**，否则中文不回退） |
| 正文字号 | 双栏 7 pt；单栏 6.5 pt |
| 轴标签 | 与正文同号 |
| 刻度标签 | 正文 − 0.4 pt |
| 图例 | 正文 − 1.0 pt |
| 子图编号 | Times New Roman 粗体，与正文同号 |
| 负号 | `axes.unicode_minus = False`（避免缺字） |

印刷后任何文字不得小于 6 pt。

## 5. 线条、标记与配色

| 元素 | 彩色版 | 灰度版 |
|---|---|---|
| 参考 > 留一 | 蓝 `#2E6DA4` 实线 | 深灰 `#262626` 实线 |
| 参考 < 留一 | 红 `#C0392B` 虚线 | 浅灰 `#8C8C8C` 虚线 |
| 留一（左列） | 空心圆，边 `#2E6DA4` | 空心圆，边 `#262626` |
| 随机（右列） | 实心圆 `#E1812C` | 实心方块 `#262626` |
| 均值 | 黑色粗线 lw 1.5 | 同 |
| 中位数 | `#4D4D4D` 虚线 | 同 |
| 机会水平 | 灰点线 lw 0.6 | 同 |
| 直方图 / 柱 | 填充 `#CFDDEC`，边 `#4A6B8A` | 填充 `#D9D9D9`，边 `#595959` |
| 95% CI 带 | `#CFDDEC` alpha 0.55 | `#D9D9D9` alpha 0.55 |

硬性要求：**去掉颜色后信息不丢失**。方向由线型区分，不依赖色相。

其他线宽：轴线 0.6 pt，刻度 2.4 pt 长 / 0.6 pt 宽，网格 0.35 pt、alpha 0.25（仅 y 向或 x 向，不画双向网格）。

## 6. 图例

- 位置：坐标区**下方**居中，`frameon=False`
- 斜率图 4 项：均值 / 参考>留一 / 参考<留一 / chance 10%（双栏两列、单栏两列）
- 分布图 3 项：均值 / 中位 / 95% CI
- 小倍数图只用**一条图例**放整图底部，不在每个面板重复
- 不重复解释横轴已标明的"留一 / 随机"

## 7. 子图编号与标题

- **图内不放标题**，图题写在正文图注里
- 双面板：坐标区左上角外侧 `(a)` `(b)`
- 小倍数：`(a) sub-01` … `(e) sub-05`，汇总面板 `(f)`
- 图内不出现"注：……"字样，说明一律进图注

## 8. 统计标注

- 位置：面板右上角，半透明白底（alpha 0.85）避免压线
- 内容：均值、中位、95% CI、p（分布图）；均值差 p（汇总图柱顶）
- 小倍数面板内**不写** Δ 与 p，统一放图注

## 9. 图注写法

格式：`图 N  标题`（空行）`图注：……`

必须包含：

1. 数据规模：run / 采集日数、试次数、类别数、机会水平
2. 编码说明：空心/实心、实线/虚线、粗黑线、点线
3. 统计口径：差值方向（随机 − 留一）、CI 的重采样单位（按 run 或按采集日）
4. 关键数值：平均差、中位差、CI、p、差值为正的组数
5. 局限：如 n=5 时 Wilcoxon 最小 p = 0.0625，不作显著性推断

图注文件存 `outputs/figures/captions/`，UTF-8 无 BOM，纯文本可直接粘贴。

## 10. 交付前检查清单

- [ ] 无图内标题，只有 `(a)` `(b)` 等编号
- [ ] 图例完整，覆盖线型、标记、均值、机会线
- [ ] 去掉颜色后仍可区分全部编码
- [ ] 成品宽度 ≤ 170 mm（双栏）/ ≤ 80 mm（单栏）
- [ ] TIFF 为 600 dpi + LZW，PDF 字体已嵌入
- [ ] 印刷字号 ≥ 6 pt
- [ ] 统计框不遮挡数据，p 值未被截断
- [ ] 图注含 n、CI 定义、p、局限
- [ ] 图内无"注："文字
- [ ] 600 dpi 原图逐张检查（200 dpi 预览看不清属正常）

## 11. 可复用代码骨架

```python
MM = 1 / 25.4
plt.rcParams.update({
    "font.family": ["Times New Roman", "SimSun"],   # 列表才会回退中文
    "axes.unicode_minus": False,
    "pdf.fonttype": 42,
    "font.size": 7,
    "axes.labelsize": 7,
    "axes.titlesize": 7.5,
    "xtick.labelsize": 6.6,
    "ytick.labelsize": 6.6,
    "legend.fontsize": 6.2,
    "axes.linewidth": 0.6,
    "xtick.major.width": 0.6,
    "ytick.major.width": 0.6,
    "xtick.major.size": 2.4,
    "ytick.major.size": 2.4,
    "lines.linewidth": 0.7,
    "grid.linewidth": 0.35,
    "grid.alpha": 0.25,
})

# 版式：优先 constrained layout，不要用 tight_layout
fig, axes = plt.subplots(
    2, 3, figsize=(170 * MM, 112 * MM), layout="constrained"
)
# 底部留白给图例
fig.get_layout_engine().set(w_pad=0.04, h_pad=0.05, rect=(0, 0.085, 1, 1))

# 子图编号（坐标区外侧，不加标题）
ax.text(0.0, 1.02, "(a)", transform=ax.transAxes, ha="left", va="bottom",
        fontsize=7, fontweight="bold", fontfamily="Times New Roman")

# 图例放轴下方
ax.legend(handles=handles, loc="upper center", bbox_to_anchor=(0.5, -0.26),
          ncol=2, frameon=False, handlelength=1.5, columnspacing=0.9,
          fontsize=6)

# 输出：矢量 + 600 dpi 位图
fig.savefig("x.pdf", bbox_inches="tight", pad_inches=0.02)
fig.savefig("x.tif", dpi=600, bbox_inches="tight", pad_inches=0.02,
            pil_kwargs={"compression": "tiff_lzw"})
```

## 12. 已知坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 中文显示为方框或整段消失 | `font.family` 设为 `"serif"` + `font.serif` 列表，不回退 | 直接把 `font.family` 设为字体名列表 |
| 面板被裁、标签消失 | `tight_layout` 与 gridspec 冲突并静默失败 | 改用 `layout="constrained"` |
| 底部文字/脚注被切 | 文字放在图坐标负值处，紧裁边界算不到 | 用 `rect` 预留底部空间，或把说明移到图注 |
| 200 dpi 预览中文看不见 | 6 pt 字在 170 mm 宽图里只有约 8 px | 以 600 dpi 原图为准，不要据预览判断 |
| 粗体报警 `Failed to find font weight bold for SimSun` | 宋体无粗体字重 | 子图编号显式指定 `Times New Roman` |
| 降采样后频段错位 | 裸抽取 `[::k]` 无抗混叠 | 先低通再 `decimate`，默认 500 Hz 不降采样 |

## 13. 数据来源

图形直接读取：

```
outputs/loro_lodo/main_8_2/<subject>/paired_loro_<subject>.csv
outputs/loro_lodo/main_8_2/<subject>/paired_lodo_<subject>.csv
```

关键列：`day`、`group`、`n_test`、`loo_accuracy`、`reference_accuracy`、`diff_reference_minus_loo`。

CI 与 p 值由该 CSV 现算：按组（run / day）有放回重采样 5000 次取 2.5/97.5 分位；配对检验用 Wilcoxon 符号秩。
