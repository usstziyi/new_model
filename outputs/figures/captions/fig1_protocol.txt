图 1  三种划分协议下的句类准确率

图注：5 名被试、10 类句类，机会水平为 10%。柱高为 5 名被试的平均值，误差棒为被试间标准差，空心圆为单个被试。三种协议依次为：同 run 随机 5 折（同一 run 的试次同时进入训练集与测试集）、留一 run（leave-one-run-out, LORO）、留一采集日（leave-one-day-out, LODO）。三者的平均准确率分别为 22.4%、11.9% 和 9.5%：跨 run 时下降 10.5 个百分点，跨天时已低于机会水平。三档使用完全相同的特征（逐通道 log 频带功率）与分类器（收缩 LDA），唯一差别是训练集与测试集是否共享 run 或采集日。
