图 S1  留一 run 与随机 5 折划分下的逐 run 配对比较（sub-01）

图注：sub-01 共 45 个 run、2459 个试次，句类数为 10 类，机会水平为 10%。(a) 各 run 在两种划分下的句类准确率：空心圆为留一 run（leave-one-run-out, LORO）结果，实心圆为随机 5 折划分（同一 run 的试次同时出现在训练集与测试集）结果，连线连接同一 run 的两种结果，实线表示随机划分高于留一、虚线表示低于留一，粗黑线为逐 run 平均值，点线为机会水平。(b) 逐 run 准确率差值（随机划分 − 留一）的分布，实线与虚线分别为均值与中位数，灰色带为按 run 重采样的 bootstrap 95% 置信区间。45 个 run 中有 41 个差值为正；逐 run 平均准确率由留一的 12.2% 升至随机划分的 21.1%，平均差值 +9.0 个百分点（95% CI 6.4~11.7），中位差值 +6.9 个百分点，Wilcoxon 符号秩检验 p = 3.3 × 10⁻⁷。
